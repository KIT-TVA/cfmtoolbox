# Evaluation scripts (YASA4CFM)

All scripts are run from the repository root via `poetry run` inside (or they
call it themselves). Instance-set variant only throughout.

## Scaling evaluation (RQ1.1 depth, RQ1.2 interval size)

- `run_parameter_eval.sh` — see below.
- `results/run_batch.sh` — the batch runner used for the depth × interval
  scaling evaluation (`results/README.md` has full provenance).
- `parse_eval_results.py` — parses the scaling logs into `results.csv` + pivots.
- `make_figures.py` — generates the TikZ/pgfplots figures from `results.csv`
  into `figures/` (see `results/README.md`).

## Parameter-influence evaluation (RQ2: t, m, c)

- `run_parameter_eval.sh` — for each model runs, averaged over `--r` repetitions
  (default 10), instance-set variant:
  - t experiment: t ∈ {1,2,3}, m = 5, c = 50 → sampling time
  - m experiment: m ∈ {1,5,10,15,20}, t = 2, c = 50 → sampling time + sample size
  - c experiment: c ∈ {50,500,1000}, t = 2, m = 5 → sampling time
- `parse_parameter_eval_results.py` — parses the logs into `results.csv`
  (long format: experiment, param, model, r, avg time / sample size, walltime,
  status) and pivot tables `summary_{time,size}_{t,m,c}.csv`.
- `models/` — the six evaluation models with `characteristics.csv`
  (generated by `model_characteristics.py`: features, CFM depth with root = 1,
  max multiplicative interval upper bound).
- `make_rq3_figures.py` — generates the RQ3 TikZ/pgfplots figures from
  `param_results/results.csv` into `figures/`: `rq3_time.tex` (one log-scale
  time axis per experiment t/m/c, lines = models), `rq3_size.tex` (sample
  size over m), and `figures/standalone/axis_rq3_{time_t,time_m,time_c,size_m}.tex`.

Usage:

    ./tests/eval/run_parameter_eval.sh MODEL.json [MODEL.json ...]
    ./tests/eval/run_parameter_eval.sh                    # uses tests/eval/models/*.json
    python3 tests/eval/parse_parameter_eval_results.py --results-dir tests/eval/param_results
    python3 tests/eval/make_rq3_figures.py --results tests/eval/param_results/results.csv

The batch executed for this paper ran the models cheapest-first with
`--r 10 --model-r model_b:5` (Model B, the largest model, uses r = 5).
